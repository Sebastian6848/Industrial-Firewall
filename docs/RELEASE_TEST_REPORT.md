## 交付边界

- 互联网或现场工控网络的在线 IPS 阻断须按网卡、驱动、配置及拓扑单独验收。上述回放只确认 Suricata 对这些场景的规则判定。部分工业协议采用有限报文特征，边界见 [协议说明](../plugins/security/icsguard/README.md)。
- 6,000 条 VPN 隧道并发、现场双机故障切换和 VPN 重连时间未测；不能据配置页面的通过判定这些指标达标。
- 当前可信计算覆盖软件完整性检查，未实现或验收 TPM/TPCM 硬件信任根、远程证明及可信启动链。
- NC-Link MQTT 策略未覆盖 TLS 密文、其他 NC-Link 传输和完整机床业务模型。应用规则数量不等同于真实现场流量识别率。
- 下载防病毒覆盖已配置显式代理上的可见 HTTP。对端到端加密 HTTPS、直连和超限文件不做默认内容检查。
- ISO 使用受信发布包；滚动仓库后续发生变化时，应使用同一产品源码及新的受信锁定输入重新构建并复测。
