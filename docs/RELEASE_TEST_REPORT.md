## 验证范围

- 在线 IPS 的实际丢包、吞吐及误报取决于网卡、驱动、流量路径和策略；离线回放结果仅覆盖所列报文场景。部分工业协议使用有限特征匹配，详见[协议说明](../plugins/security/icsguard/README.md)。
- VPN 并发容量、真实双机故障切换、VPN 连接保持和重连时间尚未进行专项基准测试。
- 软件完整性监测已实现；TPM/TPCM 硬件信任根、远程证明和可信启动链尚未实现。
- NC-Link 策略主要覆盖明文 MQTT 主题，不解析 TLS 密文、完整业务模型或机床对象级写值权限。
- 防病毒默认检查显式代理上的可见 HTTP；HTTPS、直连及超限文件不在默认内容检查范围内。
- Secure Boot 未验证。
