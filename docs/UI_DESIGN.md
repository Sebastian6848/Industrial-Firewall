# 功能页面设计约定

产品页面采用统一的布局规范：保留现有橙色主题、原生页面标题、字体、标签页、功能分区及阅读顺序。只改进局部布局、间距、字段对齐、按钮和弹窗等部件，不另建配色系统、不增加重复导航、不重排整页。


- 主要操作继续使用当前主题的 `btn-primary` 橙色，普通操作使用 `btn-default`。
- 软件源设置通过带图标和文字的“软件源连接设置”按钮打开弹窗，保留原有插件列表、搜索位置及列顺序。
- 防病毒保留状态卡片、原有两个标签页和字段排列；修正输入宽度及标签对齐，高级配置改为明确的展开按钮。
- 应用识别保留原有常规/规则标签、表单及按钮位置，统计与识别库保持原先的上下顺序，实时流量保留原工具栏。
- 按钮保持可见的键盘焦点；窄屏只调整字段宽度和按钮换行。
- 仪表盘默认将资源、接口与防火墙、服务与流量按行对齐。长列表在卡片内滚动，窄屏逐行折叠。编辑时可拖动卡片底部的橙色手柄并保存高度；已保存的个人布局继续优先使用。仪表盘局部样式位于 `src/opnsense/www/css/dashboard-layout.css`。

局部样式在 `src/opnsense/www/css/industrial-ui.css`，仅作用于 `.feature-ui`，不覆盖页面框架、全局字体及主题配色。颜色继续由现有主题控制。
