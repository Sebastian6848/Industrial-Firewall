# 功能页面设计约定

本轮覆盖插件管理、防病毒，以及应用识别的连接、规则、统计与实时流量页面。采用 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 的设计流程，保留现有 Bootstrap、Volt、API 和包管理机制。

## 视觉与交互

- 文字深蓝灰 `#20324b`，辅助文字 `#63748b`，页面浅灰 `#f3f5f8`，白色内容面板，主操作蓝 `#285db2`，正常状态绿 `#187765`。
- 中文采用系统无衬线字体，不下载外部字体。页面标题 25px，分区标题 16px，字段及按钮 13px，说明 12px。
- 页面标题、导航、工具栏、内容与操作区各自对齐。边框区分功能边界，不为每个数据项添加独立卡片。
- 设置、展开、诊断、筛选均使用明确的按钮或导航，含图标、文字及键盘焦点；不把裸文字当作隐藏功能入口。
- 状态用文字和颜色共同表达，后台加载和操作结果使用可读状态区域。没有数据时给出下一步操作，不展示虚构指标。
- 窄屏表单变成单列，宽表格在内部滚动。保留减少动态效果的系统偏好。

## 页面结构

插件管理把软件源设置放入“连接设置”按钮打开的弹窗；主页面提供全部、已安装、本地定制筛选及名称/功能搜索。插件说明放在名称下方，版本、来源和操作独立成列。

防病毒顶部集中显示扫描组件状态。扫描配置分为客户端接入、文件扫描与病毒库更新，另一个标签页显示病毒库和诊断日志。高级配置使用带展开状态的按钮。

应用识别共用连接与规则、实时流量、应用与识别库三个明确入口。采集连接表单与连接诊断分区，保留访问令牌映射和原有 API。应用统计与识别库使用统一的表格、搜索、分页与空状态。

共用样式在 `src/opnsense/www/css/industrial-ui.css`，通过 `.if-ui` 限定内容组件；当前页面通过 `if-console-view` 调整字体及面包屑。插件页面引用此 core 资源，热部署需同时更新 core 与插件。不要把这些样式无条件覆盖所有原生页面。
