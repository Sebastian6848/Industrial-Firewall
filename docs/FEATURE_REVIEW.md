# 功能说明

本页介绍系统模块及配置入口。完整操作步骤见[安装与使用说明](manual/安装与使用说明.md)，验证范围见[版本验证报告](RELEASE_TEST_REPORT.md)。

## 管理入口

| 入口 | 功能 |
| --- | --- |
| 总览 → 仪表盘 | 系统资源、接口、服务和流量；支持保存卡片布局及高度 |
| 防火墙 → 规则 | 统一管理接口、浮动及分组规则 |
| 防火墙 → 工业协议白名单 | 配置受控设备、协议操作和默认拒绝范围 |
| 防火墙 → 工业安全 | 设备分组、访问矩阵、完整性监测和集中管理 |
| 服务 → 应用识别 | 采集连接、实时流量、内置及自定义识别规则 |
| 服务 → 防病毒 | 下载扫描、病毒库更新、引擎启停和诊断 |
| 服务 → 入侵检测 | IDS/IPS 模式、签名规则及告警 |
| VPN → IPsec / OpenVPN | 隧道配置、认证、客户端及连接状态 |
| 系统 → 高可用性 | CARP、pfsync 和配置同步 |
| 系统 → 插件 | 插件目录、安装状态与软件源连接设置 |

## 工业协议与 NC-Link

白名单在配置的协议、地址和端口范围内生效。Modbus TCP、DNP3、S7comm、MQTT、NC-Link 和 EtherNet/IP/CIP 提供相应操作或业务主题控制；IEC 104、FINS/TCP、MELSEC MC/SLMP、BACnet/IP 和 OPC UA TCP 提供限定范围的报文特征匹配。

编辑器提供操作码说明、常用读写预设及默认端口。NC-Link 可约束主题前缀、设备标识、业务方向及发布/订阅。具体支持范围见[协议插件文档](../plugins/security/icsguard/README.md)与[NC-Link 说明](NCLINK_ASSESSMENT.md)。

## 应用识别

ntopng/nDPI 负责流量采集与协议识别，域名特征用于辅助归类。本地自定义规则优先；内置条目和本地规则使用同一列表，支持按来源筛选、添加、编辑及 JSON/CSV 导入导出。

域名辅助识别依赖可见的服务域名。隐藏域名、共享域名、加密 DNS 和未覆盖的采集接口会影响结果。识别统计不自动生成封禁规则。

## 下载防病毒

“防病毒配置”管理监听接口、客户端网段及扫描大小；“病毒库与诊断”管理更新设置和日志。页面顶部统一控制 ClamAV、C-ICAP 和 Squid 扫描链路。应用设置失败时，会尝试回退受管字段并恢复服务。

扫描链路检查使用普通文件与 EICAR 测试字符串。HTTPS 隧道、未经过显式代理的流量及超限文件的处理范围见[防病毒插件说明](../plugins/security/clamav/README.md)。

## 微隔离与完整性

设备分组支持静态地址或 CIDR，分组间地址应保持互不重叠。访问矩阵按源组、目标组、协议和端口控制通信，支持预览、应用与策略回退。应保留独立管理通道，并从设备两侧验证正常及禁止流量。

完整性监测比较文件摘要、权限、所有者和文件存在性。建立或更新基线前，应确认文件来自受信版本。该模块提供软件级变化检测。

## 集中管理与高可用

集中管理使用 HTTPS 和专用 API 用户，支持查询状态、审计、策略预览与隔离配置分发。节点凭据与完整性基线不随策略分发。

高可用基于 CARP、pfsync 和配置同步，两端需要相同版本及插件。切换时间、连接保持与 VPN 重连行为应在目标拓扑中验证。

## 插件与维护

插件目录使用受信签名仓库。软件源代理通过页面按钮配置，首次获取目录需要联网；连接失败时保留已有目录。详见[插件生态与软件源](PLUGIN_ECOSYSTEM.md)。

包含旧格式规则的备份可通过兼容入口检查和迁移；恢复前应在相同版本的测试环境验证。生产升级前保存配置备份，并参阅[开发指南](DEVELOPMENT.md)和[镜像构建说明](../tools/release/README.md)。
