# NC-Link 支持说明

NC-Link 通过 MQTT 主题表达注册、模型、查询、采样、通知与控制等业务。防火墙提供主题级通信策略和审计；驱动、适配器及观察代理作为独立参考实现提供。

## 防火墙侧能力

| 能力 | 支持范围 |
| --- | --- |
| MQTT 解析 | 使用 Suricata 对明文 MQTT 的解析结果匹配业务主题 |
| 通信方向 | 可分别约束 PUBLISH、SUBSCRIBE 及请求/响应方向 |
| 主题范围 | 可配置主题根前缀、设备标识、通道和业务端点 |
| 业务路径 | 支持 Register、Probe、Query、Sample、Notify、Discovery 等相关主题 |
| 订阅过滤 | 对需要的驱动订阅过滤器显式授权；订阅许可不自动授予发布许可 |
| 默认拒绝 | 在配置的地址、端口和报文范围内拒绝未知或未授权主题 |
| 审计 | 分别展示策略动作与引擎记录的实际处置 |

允许规则按事务处理，不使用 Suricata pass 规则绕过后续请求。在线 IDS 只产生告警；需要实际阻断时应启用并验证内联 IPS。

## 驱动与适配器

[NC-Link 驱动](../contrib/nclink-driver/README.md)提供 MQTT 接入、注册与模型配对、多设备通道隔离，以及可选的 TCP JSON 接收路径。该驱动是独立的 JSON-SCADA 主机组件，需配置其 MQTT、数据库和设备模型环境。

[适配器参考源码](../contrib/nclink-adapter/README.md)用于设备侧集成。参考组件不随防火墙 ISO 自动启用；部署前需要与目标机床和数据库完成互通测试。

MQTT 观察代理提供解码与日志记录。它不作为白名单强制执行点，不能替代防火墙策略或 broker ACL。

## 支持边界

- TLS 未在受信节点终止时，防火墙不能读取加密主题或业务内容。
- 当前策略不执行完整 NC-Link JSON 对象权限、数据项值域、模型变更和方法参数授权。
- TCP JSON 驱动接收能力不代表防火墙支持原生 NC-Link TCP 的内容白名单。
- MQTT over WebSocket、GMTLS 双证书和 TPCM 远程证明尚未作为已验证能力提供。
- 完整的设备身份、会话及重放防护需要 broker、应用组件和设备侧共同实现。

## 验证与部署

协议配置、离线报文和驱动测试结果见[版本验证报告](RELEASE_TEST_REPORT.md)。现场联调应覆盖合法注册与采样、跨设备身份冲突、越权主题、未知主题、通配订阅、断线恢复、TCP 分段/合并和加密边界。
