# NC-Link 适配器参考源码

基于项目工作区中的无证书适配器快照，保留 ModBus、MTConnect 与 OPC-UA 的 C/C++ 源码、CMake 文件及随附第三方源码头文件。编译产物、运行日志、设备连接配置、示例现场模型和证书不纳入仓库。

这是设备侧组件，不编入防火墙 ISO。构建前需要为目标平台提供 Paho MQTT C/C++ 库；OPC-UA 组件还需与所用头文件兼容的 open62541 库。原 CMake 文件的库路径按参考环境编写，移植时需要指向实际依赖。启动时应按现场协议和凭据配置设备及 MQTT broker，勿启用匿名公网访问。此快照不代表真实设备、国密或硬件可信接入已经验收。
