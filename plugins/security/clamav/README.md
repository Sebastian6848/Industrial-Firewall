# 防病毒统一配置

安装 `os-clamav` 会带齐 `os-c-icap`、`os-squid` 和扫描引擎依赖。日常使用入口为 **服务 → 防病毒 → 防病毒配置与诊断**（`/ui/clamav/gateway/`）。应用识别继续单独管理。

在“防病毒配置”选择代理监听接口和端口，设置允许使用代理的客户端地址或 CIDR、最大扫描文件大小，然后点击“保存扫描配置”。页面顶部的“启动防病毒 / 停止防病毒”使用已保存的配置，一键控制三个扫描服务。无需手工填写内部扫描地址或分别启动三个插件。设置直接读写现有组件模型，没有第二套需要同步的配置副本。原有缓存、认证、上游代理、自定义病毒库等高级设置保留；内部扫描连接、扫描失败拒绝策略和客户端允许网段由统一页面接管。已有透明代理或 HTTPS 解密配置时会拒绝直接切换，要求先在高级页面确认。

客户端需要配置显式 HTTP 代理，并由原有防火墙规则允许连接代理端口。可以选择已启用的静态接口或具有当前 IPv4 地址的 DHCP 接口，DHCP 地址变化后会重新绑定所选接口。仅监听本机回环时，可通过本机或 SSH 转发使用。客户端需在访问白名单中。不会自动创建 NAT、开放公网代理、启用 TLS 解密或接管应用识别。

启动防病毒或保存正在使用的扫描配置时，会在后台生成三组件配置，依序等待扫描引擎、扫描连接和代理就绪；首次启用会下载所需病毒库。最后以本机短暂 HTTP 服务验证普通文件通过及 EICAR 测试样本阻断，服务随测试结束关闭，测试样本只保留在内存中。自检当前需要可用的本机 IPv4 地址和 IPv4 代理监听地址；DHCP 接口可用于承载自检样本。

应用失败会回退本次接管的配置字段并尝试恢复组件服务，不还原其他系统配置；检测到这些字段被并发修改时不会覆盖并发修改。断电或进程被强制终止不保证自动回退，应查看系统配置备份及诊断状态。重复提交会被拒绝；重启后遗留任务在 15 分钟内保持忙碌保护，之后可重试。

在“病毒库与诊断”中独立保存自动更新和更新代理设置，只应用病毒库更新进程。自动更新和“立即检查病毒库更新”使用同一组已保存的代理设置；停止防病毒不会停止自动更新。即使关闭自动更新，手动更新配置仍保持有效；手动更新时暂时停止自动更新进程以避免争用数据库锁。运行状态、病毒库版本及各组件诊断日志都在本页查看。高级页面继续可用，修改后统一页面会提示部分关联设置不一致。

## 检测范围

只扫描经过此显式代理的明文 HTTP 内容；HTTPS CONNECT 隧道、未经过代理的流量及超过配置大小的文件不保证扫描。文件在完整扫描前不向客户端流式放出；扫描组件失败不自动放行。EICAR 自检会在检测日志中产生预期病毒记录。

## 验证

在隔离审核设备上运行：

```sh
php /usr/plugins/security/clamav/tests/gateway_test.php
configctl clamav gateway_status
configctl clamav gateway_logs
```

测试覆盖输入拒绝、扫描例外接管及四个模型的失败回退。浏览器及真实代理链验证另见 core 的 `docs/FEATURE_REVIEW.md`。所有配置备份和后台任务状态位于设备本地，不提交到源码仓库。
